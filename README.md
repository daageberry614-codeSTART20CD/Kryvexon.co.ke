# Veltroniq — Informational website

This is a static HTML/CSS/JavaScript website for Veltroniq's research phase. It does not claim that a mining operation exists, does not sell packages, and does not accept payments.

## Publish with GitHub Pages

1. Create a repository on GitHub named `veltroniq`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then save.
6. Wait for GitHub Pages to publish the site; the published URL will appear in Settings → Pages.

## Before any commercial launch

- Verify real equipment and operating costs.
- Establish a legitimate business and get relevant legal/tax guidance.
- Obtain approval and merchant credentials from a payment provider before enabling real payments.
- Build a secure backend/database before adding accounts, balances, admin tools, deposits or withdrawals.
- Do not promise fixed mining profits or display unverified earnings.
- Do not ask customers for Mobile Money PINs or banking passwords.
